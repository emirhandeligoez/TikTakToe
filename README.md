TicTacToe 🎮
Ein klassisches Tic-Tac-Toe Spiel, entwickelt mit C# und Windows Forms. 
Das Projekt bietet sowohl einen lokalen Mehrspieler-Modus als auch einen Einzelspieler-Modus gegen einen Computer mit verschiedenen Schwierigkeitsgraden.

🚀 Features
PvP-Modus: Spiele lokal gegen einen Freund (Spieler X vs. Spieler O).

PvE-Modus: Tritt gegen eine KI an.

Zwei Schwierigkeitsstufen:

Leicht: Der Computer wählt zufällige Felder.

Mittel: Der Computer erkennt Siegchancen und blockt deine Züge strategisch.

Statistiken: Verfolgt Siege für X, Siege für O und die Anzahl der Unentschieden.

Individueller Start: Wähle aus, ob Spieler X oder Spieler O die Runde beginnen soll.

Reset-Funktion: Setze das aktuelle Spiel oder die gesamte Statistik jederzeit zurück.
